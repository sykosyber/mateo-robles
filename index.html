Selected Work

Engines

Seven generative-art engines that run live in the browser. Each grows a plate from a mathematical system, from strange attractors and interference fields to branching growth, and every plate is seeded, so any image can be made again.

Canvas 2D and WebGL2, no libraries. Each engine is one self-contained HTML file with live controls. Gyre integrates a 3D attractor with RK4 and lets colour carry depth; Interferentia draws only the contours of the difference between two fields it never shows.
